# README screenshots

Put PNG/WebP captures here for the main `README.md` gallery.

Suggested filenames (match the commented block in the root README):

| File | Subject |
| --- | --- |
| `desktop.png` | Full desktop (bar + wallpaper + a couple of windows) |
| `wallpaper-picker.png` | Cover Flow wallpaper overlay |
| `settings.png` | Settings panel (any tab; Wallpaper or Theme works well) |

Tips:

- Capture at a consistent resolution (e.g. 1920×1080 crop).
- Prefer a dark bundled theme so chrome reads clearly on GitHub’s light and dark UI.
- After adding files, uncomment the image links at the top of `/README.md`.
